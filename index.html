홍보 전 일정 조율 필요

센터장님 메시지는 ‘다음 주 초 마무리·다음 주말 홍보 시작’을 요청하지만 원본에는 ‘10월 말–11월 초 홍보’로 기재되어 있습니다. 메시지 작성일과 실제 홍보 시작일을 확인하고 일정을 하나로 맞춰야 합니다.

01 / CAPACITY

실제 운영 가능성

해커톤 정원과 인턴 정원을 별도로 정하고, 연구팀이 수용 가능한 인원에서 역산합니다. 공간·장비·데이터·행정 담당·예산을 홍보 전에 확정합니다.

담당: 미정 / 해커톤 정원: 미정 / 인턴 정원: 미정 / 운영예산: 미정

02 / RESEARCH TOPICS

연구팀별 참여주제

팀별로 1쪽 과제 카드를 준비합니다. 연구질문, 필수·선택 역량, 제공 데이터와 장비, 2일 해커톤의 최소 결과물, 1개월 인턴의 확장 목표를 명시합니다. 실제 참여주제는 각 팀의 확인이 필요합니다.

참여 연구팀: 미정 / 주제 책임자: 미정 / 과제 카드 취합일: 미정

03 / MENTORING

멘토 부담과 지원체계

주제별 주 멘토와 백업 멘토를 지정하고, 멘토당 수용 인원과 주간 투입시간을 먼저 합의합니다. 사전학습 공통자료·FAQ·정해진 질의 시간을 활용해 반복 문의를 줄입니다.

멘토 배정: 미정 / 주간 투입시간: 미정 / 멘토당 인원: 미정

04 / FAIR EVALUATION

해커톤 평가방식

원본의 네 기준을 공통 루브릭으로 구체화합니다. 결과물의 완성도 외에 가설 설정, 피드백 반영, 개인별 기여, 다음 연구 제안을 관찰합니다. 팀 결과와 개인 평가를 구분하고, 복수 평가자의 독립 채점 후 편차를 조율합니다.

기준별 배점: 미정 / 평가자: 미정 / 개인 기여 기록 방식: 미정

05 / CONTINUITY

인턴 연구로의 연결

해커톤 후 참가자의 주제 선호와 멘토의 수용 가능성을 함께 확인합니다. 인턴 확정 시 연구계획·주간 피드백·최종 공유회 일정을 안내하고, 후속 참여는 희망자 동의를 받아 연결합니다.

매칭 방식: 미정 / 1월·2월 트랙 정원: 미정 / 최종 공유회: 미정

06 / LAUNCH READINESS

홍보 전 최종 확인

지원자격·신청방법·제출물·평가기준·지원조건·문의처를 공개 문안에 명시합니다. 외부 협력기관의 지원 및 후원 표기는 확인 후 확정하고, 신청 시 개인정보 수집과 결과물 사용 범위를 안내합니다.

신청 링크: 미정 / 공개 문안 승인: 미정 / 홍보 시작일: 미정
